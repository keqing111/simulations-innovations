# 有界资源定价匹配：实现与验证

目标：在S1最大可行阈值内，用真实共享资源负载指导带权指派，不改变原生补齐、scaling、Local或pipeline。用户已要求直接优先完成算法优化；本轮为有界研究实现，不提交/推送。

接口：`DecompositionOptions::resource_rounds` 默认0，允许0..8，仅S1可用；`FastAll2All::decompose(options,stats,topology,pending)` 增加可选拓扑和实际GPU剩余量，旧调用保持兼容。Global只在启用时透传balance后的pending；CLI新增`--resource-rounds`。无需新生产类。

规则：每轮先求S1阈值与seed。缓存允许边的真实字节/带宽贡献。按seed资源工作量归一化形成非负价格，进行固定次数最小费用完美指派；每次用试探匹配的归一化资源负载累加价格。仅以同一Topology模型下的真实阶段时间严格改善来替换seed。匹配边必须满足残量>=最大可行阈值，实际最小残量仍由原扣减入口计算；每轮后扣真实pending。

价格是共享资源目标的代理，并非精确最小瓶颈解；传播只在完整阶段接受目标中评价，未把传播与字节费用直接相加。固定次数带权匹配不依赖相邻阶段等系数，不删边/插边/枚举置换。保持本轮q不表示后续K不增加，也不保证完整pipeline或全计划非退化。

验证顺序：

- [x] 写CLI失败测试：CE-1达到345.6us，G1/G4、scaling开/关；默认关闭兼容；参数冲突拒绝；Zipf逐对交付与原系数扣减。
- [x] 实现有限资源定价与完整匹配，CPU计时包括评分/拓扑工作，stats报告提案数及接受次数。
- [x] N8/16、G4、均匀/Zipf、小/大负载固定面板对比原生/S1/新策略，报告退化、K、规划开销。见 `RESOURCE_MATCHING_REPORT.md`；最终完整回归另记录。

复杂度：在S1现有阈值搜索外，每轮至多B次O(n³)指派，加真实路径贡献缓存与B次阶段评分；B<=8。预处理和评分不得排除在新方法规划成本外而冒称低成本。
