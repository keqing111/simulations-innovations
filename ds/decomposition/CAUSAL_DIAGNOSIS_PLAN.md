# 原生优势区与单决策因果诊断

用户要求：解释原有方案什么时候好，并定位局部优化导致后续损失的具体阶段；拓展多个合理多DC瓶颈配置，不改变计价规则。

本轮不设计新调度算法。先增加研究用 `--resource-skip-step k`：只在第k个0-based阶段不执行资源定价，选同一前缀下最大瓶颈seed，之后照常运行资源算法。保存本轮seed/实际匹配及两者同前缀下的阶段成本。默认不跳过，原输出计划不变；不将这种整后缀重放作为在线算法。

验证：CE-1跳过第0次改动恢复425.6us；所有记录的seed和选中匹配为完美匹配；不跳过计划与既有档案完全相同；反事实与原执行在k之前逐阶段相同，并严格对账真实交付、资源总量和流水线。对N16大微扰、N8大Zipf的所有实际发生修改的阶段分别只撤销一次，不把多次撤销效应相加冒充独立因果贡献。

之后分开调查3DC独立WAN瓶颈、共享网关瓶颈与异构WAN；先统一可重放的路径/资源输出，再配对相同输入。结果明确区分阶段序列化、传播、后续阶段数和机内重叠。
