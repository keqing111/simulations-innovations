# 检索记录与证据边界

日期：2026-10-29；资料整理于FAST原生工作区。用户请求：先调研并记录相关论文，再讨论优化；本轮没有新算法实现、没有运行论文作者代码、没有修改旧实验或Git上传。

## 范围与方法

围绕 topology-aware collective / all-to-all synthesis、Birkhoff decomposition / sparse scheduling / reconfiguration、WAN collective / flow dependency / rolling horizon 三组主题检索，追溯论文引用与作者公开资料。优先会议、作者/机构网页及公开PDF；arXiv用于作者版本或明确标为预印本的工作。不以博客、搜索摘要或聚合站性能描述作为方法证据。

这是一轮定向研究，不是穷尽性系统综述。检索没有证明“此前无人做过”，也没有据此推导正式新颖性结论。PAPERS.csv中的reading_level用于区分阅读程度，而不是把下载等同于通读。

## 书目与版本核对

- TE-CCL为SIGCOMM 2024；ForestColl为NSDI 2026；TACOS正式会议信息由MICRO 2024程序核验，本地为arXiv v3作者稿。
- Birkhoff+正式期刊为ToN 2021，本地公开稿是2020年arXiv v1；最终版由机构开放记录另行核验，下载最终版超时。后续引用定理编号或复现细节前应核对最终版。
- Eclipse登记2016正式标题；2015预印本另一标题不是另一篇论文。
- WAN依赖论文由作者实验室ICDCS 2026列表和公开全文核验。未采用未在一手来源核对的DOI。
- NOTION由作者发表列表C111核验为NOMS 2026，全文未取得；不报告其算法细节或性能结论。
- 动态分层BvN目前核验到arXiv:2602.22756v1，页面声明已投稿，未核验正式接收；不计入已发表论文数。

## 本地资料

10份新增PDF均来自论文作者、会议或arXiv公开版本，已用PDF解析器打开检查页数。它们只作为本工作区研究材料，不代表再分发许可。路径登记于PAPERS.csv；FAST沿用已有论文文件，Varys本轮网页读取后未成功保存PDF。未下载NOTION、动态分层BvN全文PDF。

本轮不增加矩阵哈希要求，也不重新审计旧结果。文献记录重点是可追溯来源、版本与实际阅读范围，而不是额外复杂的资产管理。
