## 1. 两个层次：BvN定义可行域，拓扑定义目标

用户提出的划分是恰当的，但应补充“阶段代价”和“剩余状态”，否则容易把单阶段最优当成整体最优。

| 层次 | 数学对象 | 回答什么 |
|---|---|---|
| 分解可行性 | 残余矩阵R、置换P、提取系数q | 能否合法扣减并完整交付 |
| 拓扑计价 | 固定路径、资源带宽、传播、真实载荷U | 一个动作花多少时间 |
| 启发式选择 | 当前代价与剩余状态的近似 | 多个合法动作中选哪个 |

本轮研究对象是当前完整FAST集成路径：相同补齐、balance与pipeline，修改服务器级分解。独立partial-BvN模块不在此处改写。BvN的一般可行系数允许小于等于选中最小残量；**当前代码及本轮设计边界更严格，固定使用实际最小残量**，不任意切碎一个匹配。

FAST已使用机内/机间层次及BvN，论文的简化起点包含均匀链路、全双截面网络。本工作不能声称首次发现BvN或FAST完全没有拓扑意识；关注的是其中间共享资源扩展。[FAST，§3、§4.2](https://www.usenix.org/system/files/nsdi26-lei-yiran.pdf)

## 2. 状态、动作与正确性

### 2.1 不混淆辅助残余和真实数据

```text
R[i,j]     当前补齐后的服务器辅助残余，非负整数
ρ          R的公共行和、公共列和
U[i,j,u]   balance后，同索引GPU通道u仍需真实发送的单位数
κ          本次固定的原生scaling factor
b          每个真实流量单位的字节数
```

U只记录服务器间真实通信；同server部分由原生机内流程处理。虚拟补齐只在R中，不能算成网络服务。初态需要满足每个真实通道 `U[i,j,u] <= κ R[i,j]`；原生补齐/缩放的交付核验负责确认这一不变量。

一个动作由正残余支持中的完美匹配P决定：

```text
P[i,j] ∈ {0,1}
每行P之和 = 1；每列P之和 = 1
选中边必须满足 R[i,j] > 0
q(P) = 选中边R[i,j]的实际最小值
R' = R − q(P)P
```

选中(i,j)时，通道u的真实发送量为：

```text
y[i,j,u] = min(κq, U[i,j,u])；未选中时y=0
U' = U − y
```

### 2.2 命题一：改变匹配目标不会破坏分解，只要维持上述约束

证明分四步：

1. **匹配存在。** 若ρ>0，对任意行集合I，其ρ|I|流量只能进入正支持邻列N(I)；邻列总容量至多ρ|N(I)|，故|N(I)|>=|I|，满足Hall条件。
2. **残余可行。** q是选中最小值，因此R'非负；每行列恰扣q，公共行列和变为ρ−q。仍非零时可重复第一步。
3. **有限终止。** 每轮至少一条正边变零、不引入新正边。若初始正边数为m，则最多m轮终止。该上界不表示得到最少阶段数。
4. **真实交付。** 由 `U<=κR` 得 `max(U−κq,0)<=κ(R−q)`，未选中边不变；所以该不变量逐轮保持。R最终为零时U也为零。

因此，拓扑只能改变“在可行集合中选什么”，不需要修改真实字节以保证正确性。这能作为方法章节的正确性命题，但不是新颖性声明或性能近似保证。

## 3. 将静态拓扑映射为阶段代价

对每条固定路径预存：

```text
H[e,i,j,u] = 1，若该通道使用有向共享资源e，否则为0
B[e]       资源e的容量，字节/时间
τ[i,j,u]   单向路径传播时间
```

H、B、τ静态；阶段负载与代价因P、q和U而变化。

```text
w[e] = Σ(i,j,u) H[e,i,j,u] · b · y[i,j,u] / B[e]
S(P,q,U) = max_e w[e]
A(P,q,U) = max{τ[i,j,u]：y[i,j,u]>0}；空集合取0
F(P,q,U) = A + S
```

F与当前 `Topology::evaluate_gpu()` 保持同一容量近似，不宣称等于包级真实完成时间。RTT不直接代替τ，不增加ACK或拥塞控制机制。不同阶段网络时间按现有FAST计价累计，不新增barrier。

```text
J_network = Σ_k F(P_k,q_k,U_k)
J_FAST = J_network + H_pipeline
```

H_pipeline为原生balance、intrinsic和dispatch中未隐藏的余量，依赖整个计划，并非固定常数。以下最优性讨论默认针对J_network；若讨论完整FAST，必须保留其流水线状态或显式评价H_pipeline，不能把网络层结论直接提升为端到端保证。

## 4. 为什么原始端点目标与拓扑目标不同

### 4.1 理想端点模型中，很多不同分解本来就等价

暂取真实矩阵等于辅助矩阵、κ=b=1且无虚拟流的简化模型。若所有合法匹配每单位系数的序列化时间均为β，每阶段传播都是a，则：

```text
Σ_k q_k = ρ
J_network = Σ_k(a + βq_k) = Ka + βρ
```

当a=0，不同分解只要合法就有相同序列化时间，阶段数多不一定更慢；a>0时，减少K才直接减少Ka。这解释了为什么不能脱离计价模型讨论“阶段数效率”。

共享网络中，每单位系数代价变为依赖通信组合的s(P)：

```text
J_network = Σ_k [a(P_k) + q_k s(P_k)]
```

最大化q只处理粒度，没有控制s(P)。即使K和所有q都不变，替换匹配仍可能改变完成时间。真实载荷饱和、虚拟边和缩放取整时，应回到第3节的y与F，而不是强行假定S始终等于q乘常数。

### 4.2 命题二：固定线性边代价的完整总和不随分解改变

对任意固定边代价c，精确分解D=Σq_k P_k满足：

```text
Σ_k q_k Σ(i,j) c[i,j] P_k[i,j]
    = Σ(i,j) c[i,j] D[i,j]
```

右边只由原需求决定。对真实载荷，固定路径上的线性加权总字节同样守恒。

所以，只把每条边独占的字节/带宽或字节×某个静态权重相加，不足以解释完整调度为何更快。资源共享引入的是**同阶段求最大值、跨阶段再求和**，这是线性边总价没有表达的组合关系。

这个命题不等于所有静态信息都没用：静态代价可指导生成候选；将D变换后再投影还会改变切分和补齐，已经不是同一D上的线性计价。后者必须另证交付与映射含义，不能借此守恒式宣称全部静态方法无效。

## 5. 共享资源组合损失：一个精确恒等式

设W[e]=Σ_k w[e,k]为固定路径下资源e必须处理的总工作时间，定义：

```text
L = max_e W[e]
G = Σ_k max_e w[e,k] − max_e Σ_k w[e,k]
```

L是资源容量下界；G>=0，因为逐阶段最大值之和不小于任一资源的累计工作量。因此：

```text
J_network = 累计阶段传播 + L + G
```

对同一真实输入和固定路径，L不变。算法能改变的是累计传播与G；完整FAST还要考虑H_pipeline。

### 5.1 命题三：G=0的充要条件

**存在至少一个资源，在所有阶段都达到该阶段的最大工作量，当且仅当G=0。**

证明：取总工作量最大的资源e*。则：

```text
G = Σ_k [max_e w[e,k] − w[e*,k]]
```

每项非负，总和为零当且仅当每项均为零。反向若存在这样的共同瓶颈，该资源的总工作量等于逐阶段峰值之和，立即得G=0。

由此得到明确的场景边界：若原生计划已由同一资源贯穿主导，就没有进一步降低ΣS的空间；仍可能减少传播或机内余量，但不应期待共享资源重排的序列化收益。反之G>0只是存在下界差距，不保证端点约束下全部可消除。

### 5.2 同K反例的完整代数构造

四端点辅助需求D=P+Q，系数均为1：

```text
P = [1,0,3,2]        Q = [3,2,1,0]
```

列表按源索引给出目的。P的四条边使用共享资源e1，Q的四条边使用e2；每条真实边1单位，两资源容量均2单位/时间，传播取0，端点资源不限制。两匹配边集不交，D行列和均为2。

另一个合法分解为：

```text
P' = [3,0,1,2]       Q' = [1,2,3,0]
P + Q = P' + Q'
```

| 计划 | 阶段1资源工作(e1,e2) | 阶段2资源工作(e1,e2) | K | ΣS | L | G |
|---|---|---|---:|---:|---:|---:|
| P、Q | (2,0) | (0,2) | 2 | 4 | 2 | 2 |
| P'、Q' | (1,1) | (1,1) | 2 | 2 | 2 | 0 |

它证明BvN合法与等K不代表资源代价相同。这里是抽象共享资源模型内的构造，不冒充已给出符合指定DC物理拓扑的布线；论文的物理动机反例仍使用已有多DC实例。

## 6. 现有启发式实际上优化了什么

令M(q)为仅使用R[i,j]>=q边的完美匹配集合。阈值增大时M(q)只会缩小。

现有最大瓶颈底座先求：

```text
q* = max_P min{R[i,j]：P[i,j]=1}
```

再在M(q*)内通过价格匹配或交替环降低F。两/三边严格下降保证的是该邻域内当前阶段目标的局部最小，不保证：

- 原生匹配属于M(q*)；
- q*能得到最少K；
- 当前阶段F下降能使后续总F下降；
- 受限空间包含整个问题的优解。

已有6server微扰精确证书表明，每轮都取q*时最优网络时间36.851051ms，大于原生完整FAST的27.693916ms。该反例定位的是**我们把q最大化设为硬优先级的限制**，不是BvN可行性错误。证书及范围见[机制报告](MECHANISM_AND_EXPERIMENT_GUIDE.md#42-新的强反例硬性最大q本身排除了优于原生的解)。

### 6.1 下一步的第一项真实算法改动应是联合考虑系数与组合

在第4.1节的理想线性载荷模型中：

```text
J_network / ρ
    = Σ_k (q_k/ρ) · [a(P_k)/q_k + s(P_k)]
```

它是每单位分解进度代价的加权平均。因此 `a(P)/q(P)+s(P)` 是有目标来源的局部启发式，不是人为乘一个RTT权重。

若两个候选传播相同为a，且q大>q小，小系数候选的单位进度代价更低恰当且仅当：

```text
s(大系数候选) − s(小系数候选)
    > a · (1/q小 − 1/q大)
```

左边是改善共享资源组合带来的单位进度序列化节省，右边是小系数增加的单位进度传播成本。这给出了可解释的临界条件；它不是两个完整分解的最优性比较，因为未来可行匹配也会改变。

真实模型中应考虑以真实交付字节V替代辅助进度q，防止虚拟补齐被当成服务收益。无论用哪种进度，不能跨候选只比较本轮F，否则少传数据天然可能显得便宜。

## 7. 当前与未来的关系：数学上应近似什么

### 7.1 完整网络目标的Bellman表达

令状态x=(R,U)，J*(x)为从该状态完成全部交付的最优网络时间。固定拓扑、单位和scaling作为参数，动作仅取正支持完美匹配、系数仍为实际最小残量：

```text
J*(x) = min_P { F(x,P) + J*(x_after_P) }
J*(终态) = 0
```

这是对最优问题的定义，不是建议在线枚举求解。它明确说明了：当前阶段最短、最大系数、最大消边都只是对完整目标的不同代理。

启发式应该说明采用了什么近似，例如用J_hat近似剩余代价，或用单位进度控制局部选择。**解释清楚代理与原目标之间的关系，才是算法可解释性；给评分起名字不提供保证。**

### 7.2 一个可证明、但并不自动可靠的剩余势函数

对真实残余U定义：

```text
L(U) = 最大剩余资源工作量
Q(U) = max(
  每个发送server所有仍活动目的路径传播之和，
  每个接收server所有仍活动来源路径传播之和)
Φ(U) = L(U) + Q(U)
```

若同一server对不同GPU通道传播不同，该对取仍活动通道的最大传播。Q只统计真实活动server对，虚拟边和已完成对均为0。

**Φ是剩余网络时间下界。** 剩余ΣS>=L；每个server每阶段只能配一个对端，所以完成该server所有活动对必须至少支付这些传播的总和，剩余ΣA>=Q。两项分别属于代价的不同加数，故可相加。传播相同为a时，Q等于a乘真实残余支持图的最大行列度。

**Φ满足单步一致性。** 任一合法动作：

```text
L(U) − L(U') <= S
Q(U) − Q(U') <= A
故 Φ(U) − Φ(U') <= F
```

第一式来自max函数的次可加性；第二式因为一个阶段对每个server最多减少一个对端项，减少量不大于该阶段最大传播。于是定义：

```text
E(x,P) = F(x,P) + Φ(U') − Φ(U) >= 0
```

对于任何完整合法计划，逐阶段求和消去中间势函数：

```text
J_network = Φ(U_initial) + Σ_k E(x_k,P_k)
```

这个恒等式将“本轮便宜”改写为“本轮相对剩余下界产生多少超额”。E不是对最优调度的真实后悔值，也不表示全部超额都可避免；Φ可能很松。

### 7.3 一条有数学来源的候选规则，以及它为什么仍不能直接定稿

一种待验证规则是，在联合系数/匹配候选间最小化：

```text
score(x,P) = E(x,P) / 本轮真实交付字节V(x,P)
```

量纲为时间/字节。它同时包含传播、资源峰值、剩余工作与真实进度，没有把字节、RTT、带宽生硬相加。纯虚拟且网络代价为0的动作应单独处理，不做0除；完整FAST中可能存在的机内代价仍须另外计入。

这不是已完成的新算法，也没有全程改善保证：相同局部score仍可能留下不同的残余可行域。在固定q、真实服务量相同时，仅用L的版本与之前测试过的“当前时间+剩余容量下界”排序等价，不能换个名字当作新贡献。增加Q后下界更强，但仍未描述所有资源与端点冲突。

本轮仅作6server离线诊断：每轮枚举720个置换求该score的贪心最小值，系数取实际最小残量；并列按score、负真实字节、负q、置换字典序选择。Python浮点直接比较，仅作原型，不是数值稳健的生产规则。

| 既有案例，1024B单位 | 原生网络时间ms | Φ=L版本：score贪心网络时间ms | Φ=L+Q版本：score贪心网络时间ms |
|---|---:|---:|---:|
| P101微扰、异构WAN | 27.679817 | 24.270762 | 23.186663 |
| P101微扰、独立均匀WAN | 18.499981 | 11.197831 | 11.197831 |
| 严格均匀、异构WAN | 26.612362 | 23.857525 | **28.827198** |

全部为网络时间，不包含完整pipeline，也不代表在线速度。L+Q版本在三条实际贪心轨迹共1226个合法候选上核验E非负，并核对望远镜求和恒等式；不是所有矩阵上的数值测试或形式化证明。

结论：该思路能突破硬最大q反例，但**严格的下界推导不等于可靠的贪心动作排序**；L+Q版本反而在已知均匀例子中退化。数学分析已经指出应研究“剩余机会近似是否足够”，不能据三例选好公式直接宣布正式算法。

## 8. 拓扑信息应如何进入匹配生成，而非只做事后打分

固定一个候选阈值q，阶段边载荷及资源贡献可以预先计算。对真正满足实际最小系数为q的匹配，阶段最优问题可写成：

```text
最小化 a + t
满足：
  P为完美匹配，且只使用R[i,j]>=q的边
  至少一条选中边R[i,j]=q
  t >= Σ(i,j) w[e,i,j,q] P[i,j]，对每个共享资源e
  a >= τ_active[i,j,q] P[i,j]，对每个通信对(i,j)
```

这是**多资源min-max指派**，不是普通线性边费用指派。q=q*时“至少一条等于q”自动成立；放松阈值后不再自动成立，必须重算实际最小值并重新评价，不能将阈值冒充实际系数。

普通带权Hungarian只能优化线性边费用。对资源峰值有：

```text
max_e w[e] = max{Σ_e λ[e]w[e]：λ[e]>=0，Σ_e λ[e]=1}
```

因此资源价格λ能作为min-max目标的线性代理，指导匹配生成；但固定一组λ只给一个下界。并列瓶颈、价格变化和整数匹配的组合效应，都会使最优线性费用匹配不等于最优峰值匹配。已有价格法反例正属此类。

下一版若采用带权生成，应从上述资源约束/残余势函数推导费用含义，保留同一完整目标验收；不能只改变Kuhn遍历顺序就称为拓扑代价最优。本文不建议把这个整数模型交给在线通用求解器；它用于定义问题和检验启发式偏差。

## 9. 对论文论证和下一步算法工作的直接指导

论文不需要声称求得通解，也不必为了严谨而在线解全局优化。适当的论证结构是：

1. **可行域与正确性**：BvN残余不变量、至少消边、真实交付，明确哪些性质与启发式目标无关。
2. **优化目标与不足**：共享资源的max耦合使线性代价守恒不再提供优化方向；用G及其零条件描述原生已充分利用容量与尚有组合空间的场景。
